# ADR-0001: Monorepo и граница Rust/TypeScript

- Статус: принят
- Дата: 2026-11-11

## Контекст

Execution Engine требует одновременно быстрого интеграционного слоя и консервативного, детерминированного data plane. Раздельные репозитории на раннем этапе увеличат стоимость совместимых контрактов и CI.

## Решение

Используем один репозиторий. TypeScript обслуживает control plane, HTTP API и внешние REST-интеграции. Rust обслуживает потоковые данные, state machine, policy checks, симуляцию и, после отдельного разрешения, signing/broadcast. Общие wire-контракты версионируются; на границе запрещены числа с плавающей точкой для токенов.

## Последствия

Единый pull request проверяет обе части. Цена — два toolchain и необходимость contract tests. Критическая логика не дублируется: authoritative policy/state machine находится в Rust.
